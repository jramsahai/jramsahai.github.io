Nerd Night

A mobile-first app that helps a friend group pick a date for a get-together, no accounts needed

  • Personal
  • Builder
  • 2026
  • nerdnight.startingline.digital

The problem

Picking a date for a group hangout usually turns into a long, messy back-and-forth in a group chat, with everyone repeating their availability and no clear view of where things actually land. Most scheduling tools make this worse by asking each person to create an account or fill out a form just to say which of a handful of dates work for them.

The solution

Nerd Night lets one person set up an event with a short list of candidate dates and share a single link with the group. Anyone with the link joins by typing their name and tapping the dates that work for them, no account required, and everyone watching the link sees results update live as votes come in.

One deliberate choice: the organizer manages the event, closing voting, renaming it, deleting it, through a cookie-based admin session rather than an admin token embedded in the shared link. A token in the URL ends up sitting in browser history, where anyone with access to the device could find it; a cookie-based session avoids that. Participant names are encrypted at rest, and abuse prevention relies on rate limiting rather than requiring anyone to sign up. Events that go quiet clean themselves up automatically after 90 days.

Tech stack

A React front end talks to Firebase Cloud Functions for all writes, with Cloud Firestore as the data store and Firebase Hosting serving the app. A custom touch-friendly calendar handles multi-date selection, since off-the-shelf date pickers don't handle mobile multi-select well.
