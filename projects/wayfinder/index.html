Wayfinder

Jump to the exact moment in a video by asking for it, then search and chat across an entire video library

  • Vidyard
  • Product manager
  • 2026
  • AI project

The problem

Video demos are made to be watched start to finish, but viewers usually want one specific part: the pricing screen, the integration step, the feature someone mentioned. Scrubbing through a timeline to find it is slow, and it gets worse once there are dozens of videos to search through instead of one.

The solution

I started with a chat panel next to Vidyard's video player. A viewer types a question like "show me the reporting feature," and an LLM agent reads the video's transcript to find the matching moments. It returns those moments as references into the transcript rather than raw timestamps, and the backend checks each one against the real transcript before trusting it, so the video can only ever jump to a moment that actually exists. Matches show up as clickable buttons; clicking one seeks the player to that point, plays it, and pauses automatically when the relevant part ends.

The follow-on prototype extends the same idea from one video to an entire indexed video library. Instead of reasoning over a single transcript, a tool-calling agent can search across the whole library and return a conversational answer with clickable video cards that deep-link straight to the right timestamp in the right video, turning a library of recordings into something you can ask questions of directly.

Tech stack

A TypeScript frontend renders the chat panel and drives the video player, while a Python backend handles the language model calls and validates every result before it reaches the browser. The library version adds a vector store behind the search tool so the agent can retrieve relevant videos instead of just relevant moments in one.
