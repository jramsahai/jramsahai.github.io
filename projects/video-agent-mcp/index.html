Video Agent MCP

Generate personalized AI avatar videos by asking Claude for them in plain language

  • Work
  • Product manager
  • 2025
  • AI project

The problem

Vidyard can generate personalized AI avatar videos from campaign templates: pick a campaign, fill in variables like a first name and a company, and a video comes back a few minutes later. Doing that by hand means opening the campaign tool, knowing which campaign fits and which variables it needs, then checking back until the video is done. That is a lot of steps for someone who just met a lead and wants to send a quick follow-up.

The solution

I built an MCP server that lets Claude do all of that from a conversation. It gives Claude three tools: list the available campaigns and the variables each one needs, generate a video, and check on a video's status. A request like "I just met Devon at a conference, create a follow-up video" is enough. Claude looks through the campaigns, picks the one that fits, fills in the variables, and starts the video. If something required is missing, such as the lead's company, it asks before generating. A freestyle campaign takes this further: Claude writes the whole script itself and the avatar delivers it.

Videos take a few minutes to render, so nothing waits on them. Each request is stored as a job, and a webhook marks the job complete when the video is ready. Asking "is the video for Devon ready?" runs a fuzzy match of that question against the user's recent jobs and returns the watch link, so nobody has to keep track of a job ID. Once proven out, this project was handed over to a core development team for release to market.

Tech stack

The MCP server is a thin TypeScript adapter of about 200 lines that speaks MCP to Claude Desktop and forwards each tool call over HTTPS. The real logic lives in a small serverless API that handles authentication, campaign lookup, variable validation, rate limiting, job tracking in Redis, and the completion webhook. Keeping the adapter thin meant the same API could sit behind any other client later.
