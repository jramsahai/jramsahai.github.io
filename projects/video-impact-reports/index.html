Video Impact Reports

An analysis toolkit measuring how video views influence sales deals, joining Vidyard views with HubSpot CRM data

  • Work
  • Product manager
  • 2025

The problem

Sales and marketing teams create and share a lot of video, but the view data lives in Vidyard's platform while deal data lives in a separate CRM. Without a way to line the two up, it's hard to say whether video is actually helping close business or just a nice-to-have that everyone assumes is working.

The solution

I built an analysis toolkit that joins video view data with CRM exports (contacts, companies, and deals) to answer a handful of concrete questions: did a deal have video views before it progressed, how does pipeline created from video compare to revenue actually closed, which videos and which reps are most associated with influenced deals, and how do AI-generated avatar videos compare to conventionally recorded ones. To keep things simple, a deal counts as video-influenced if a known contact viewed a video within a 30-day window running from before the deal was created through its close date.

All reports generated from a demo dataset.

Since view data is an imperfect proxy and reasonable people can disagree about attribution rules, I paired the analysis with a validation suite that checks the numbers against known, hand-verified examples before anything goes to a stakeholder. I also chose to render the output as self-contained HTML dashboards with no external dependencies, so a report can be handed to someone as a single file and opened offline.

Tech stack

The pipeline is a set of Python scripts that load CSV exports, join them into one dataset, run a validation suite, and generate a set of self-contained HTML dashboards with inline SVG charts, with no server or JavaScript framework required.
